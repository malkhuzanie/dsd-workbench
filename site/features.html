Product · Features

A workbench, not just a splitter.

Splitting, proof, tagging, waveform editing and optional online lookup, in one app and one command-line tool that share the same engine.

Splitting

Bit-perfect cuts

  • Audio is never decoded; cuts land on the exact sample, even off a byte boundary
  • DSF and DSDIFF in, standards-conforming DSF out
  • Mono, stereo, 5.1 and beyond; any DSD rate
  • Multi-file CUE sheets (one file per side) and batches of whole folders
Splitting

Safe by default

  • Sources and CUE sheets are never modified
  • No overwriting unless you allow it
  • Atomic writes: temporary file, renamed on success
  • Cancel mid-track; real progress, throughput and time remaining
  • Free space, write access and path limits checked first
Verification

Proof, not trust

  • Re-reads every output and compares it bit by bit with the source
  • Identical / differs / missing, with a per-track integrity map
  • Detects a file that is right but shifted; checks tags and cover art
  • --verify and --verify-only with a meaningful exit code
Verification

Tested the hard way

  • An independent bit oracle checks synthetic splits with awkward cut points
  • Fuzz targets for the DSF header, ID3 tags, DSDIFF header and CUE parsing
  • Crash reports stay local; one-click diagnostics leave secrets out
CUE sheets

Forgiving about real-world sheets

  • Case-insensitive file names, .wav/.flac swapped for .dsf/.dff, Windows paths
  • Encoding detection: UTF-8, UTF-16, Shift-JIS, GBK, Windows-1252 and more
  • A Locate… button relinks missing sources
  • Pregaps (INDEX 00) and an optional hidden track 00
Waveform

No CUE sheet? Cut by silence

  • Zoomable waveform with draggable cut markers
  • Silence detection with tunable threshold, gap and track length
  • Ctrl-drag snaps a marker to a silent gap; loud cuts are flagged
  • Export the result as a CUE sheet
Tags

Real tagging

  • Album defaults with per-track overrides; bulk-edit any selection
  • 14 standard fields plus custom TXXX fields
  • Current tags shown beside the proposed ones
  • ISRC, catalogue number, comment and disc number kept from the CUE sheet
Tags

Tag-only mode & cover art

  • Retag existing .dsf files without re-splitting; only the tag is rewritten
  • Cover found next to the CUE sheet and embedded in every track
  • Optionally copied to the album folder as folder.jpg
Names

Names your way

  • Templates: {track:02} - {title}, folders such as {albumartist}/{album} ({year})
  • Any tag usable, including {tag:MOOD}; live preview
  • Safe on Windows, macOS and Linux; non-Latin titles kept as written
Lookup

MusicBrainz & Discogs (optional)

  • Fill titles, artists, composer, conductor, date, label and catalogue number
  • Search by what you type, a release link, or the album's own artist and title
  • Off by default: standard builds contain no network code at all
  • Flags mismatched editions by comparing track lengths; undoable
App

A comfortable workspace

  • Batch list, undo/redo, keyboard shortcuts, saved projects
  • Audition playback of either side of any cut
  • Light (paper) and dark themes; WCAG-checked colours
  • CJK titles display correctly; errors say what to do next
CLI

Scriptable

  • The GUI and CLI share one engine, so scripts behave like the app
  • --dry-run, --verify, --tag-only, --auto, --at, --lookup and more
  • Save a project from the command line and reproduce a split later
  • Headless build without audio output for servers
·Honest limits

What it doesn't do.

  • DST-compressed files are not supported (the app says so and explains what to do). Most SACD rip tools can export uncompressed DSD.
  • DSDIFF input is uncompressed only; output is always DSF.
  • Silence detection assumes the gaps between tracks are quiet; a gapless live album needs cuts placed by hand.
  • Audition playback is stereo at audition quality, not a reference DAC path.
  • Tested mostly with generated files; coverage of real-world rips and players is still growing. Please report anything odd.
